# meeting-attendees

Outlook カレンダーの予定について「いつの何という予定か」「参加者は誰か」「その参加者は whois.md 上の誰か」を答えるためのスキル。依頼は「今の予定」「明日10時の会議の参加者」のように一部だけのことが多いが、いずれも次の3ステップの部分実行として扱う。

```
1. 予定の特定      2. 参加者の取得        3. 人物照合
(calendar_search)  (read_resource)       (whois.md)
```

## 前提ツール

- `mcp__claude_ai_Microsoft_365__outlook_calendar_search` … 予定の検索。`ToolSearch` で `select:` して読み込む。
- `mcp__claude_ai_Microsoft_365__read_resource` … 予定の詳細（参加者の氏名・出欠回答・本文）を取得。同上。
- `tools/whois/whois.md` … 人物辞書。個人情報を含むため git 管理外（`.gitignore` 参照）。存在しない場合はユーザーに用意を依頼する。

## 1. 予定の特定

- 現在日時は `date "+%Y-%m-%d %H:%M %A %Z"` で確認する（このユーザーのタイムゾーンは JST）。会話の `currentDate` は日付のみで時刻を含まないため、時刻はシェルで取る。
- `outlook_calendar_search` は `query: "*"`、`afterDateTime` / `beforeDateTime` にその日の 00:00〜翌 00:00、`order: "oldest"` を指定して当日分を時系列で取得する。
- 「今の時間帯の予定」= 現在時刻が `start`〜`end` に含まれる予定。全日イベント（`isAllDay: true`、多くは `showAs: "free"`）は所在地・状態を表すだけのことが多いので、時刻指定のある予定と分けて示す。
- 「会議」を聞かれたとき、外部参加者のいない予定（参加者が本人アカウントのみ）は個人ブロックであり、実質的な会議ではない。該当する時間帯に複数の予定が重なっている場合は、他者が参加している予定を「会議」として扱い、個人ブロックは補足として挙げる。
- 予定の `start.dateTime` は指定タイムゾーン（`timeZone` フィールド）のウォールクロック文字列。UTC として再解釈しない。

## 2. 参加者の取得

- 検索結果の `attendees` はメールアドレスのみ。氏名・出欠回答・主催者が必要なときは、対象予定の `uri` を `read_resource` に渡してフル情報を取得する。
- `read_resource` の返す `organizer`（主催者）と `attendees[]`（`name` / `address` / `type` / `responseStatus`）を整理する。`responseStatus: "none"` は「未回答」と表記する。

## 3. 人物照合（whois.md）

- `tools/whois/whois.md` を読み、各参加者のメールアドレスを照合する。`whois.md` は「# 見出し（人物名）」ごとに `## account`（メールアドレス、複数可）と `## role`（役割）を持つ。
- **本人アカウントの扱い**: `whois.md` の「検索結果から除外する」に列挙されたアドレス・ドメイン（ユーザー本人の主ドメイン全体、複数ドメインのエイリアスを含む）はすべてユーザー本人。参加者がこれらだけなら「本人のみ＝個人ブロック、外部参加者なし」と結論する。
- 一致した参加者は「メールアドレス → whois.md の人物名・役割」の対応表で示す。
- `whois.md` に載っていないアドレスは「whois.md に記載なし」と明示し、ドメイン（社名の手がかり）程度は添えてよいが、推測で人物を断定しない。

## 出力の形

- 予定は「件名・日時（JST）・区分（カテゴリや主催/出席）」を1行または小さな表で示す。
- 参加者は「主催者」と「出席者」を分け、氏名・メール・出欠回答の表にする。
- **「検索結果から除外する」に該当する本人アカウントは、参加者一覧・照合結果の表に行として載せない。** 主催者欄が本人アカウントの場合も表の行としては出さず、必要なら表の外で「（主催：ユーザー本人）」のように一言添える程度に留める。予定全体の参加者が本人アカウントだけの場合は、表自体を省略し「本人のみ＝個人ブロック、外部参加者なし」とだけ述べる。
- 照合結果は whois.md の記載（人物名・役割の引用）を根拠として明記する。
