---
description: 本日受信した受信ボックスのメール一覧を取得して表示する
---

Microsoft 365 の受信ボックスから、本日(実行時点の日付)受信したメールの一覧を取得して表示して。

手順:
1. `mcp__claude_ai_Microsoft_365__outlook_email_search` を以下のパラメータで呼び出す。
   - `folderName`: "Inbox"
   - `afterDateTime`: "today"
   - `order`: "newest"
   - `limit`: 25
   - `offset`: 0
2. レスポンスの末尾に `nextOffset` が含まれる場合は、それを `offset` に指定して追加取得し、全件集める。
3. 結果を「No. / 受信日時 / 差出人 / 件名 / 未読かどうか」の表形式でまとめて出力する。
   - `No.` は表示順（新しい順）に 1 から振る連番とする。取得時の `offset` とは無関係に、表示した行に対して振り直す。
   - この連番は、ユーザーが後続の指示（返信・既読化・削除・転送など）で対象メールを「1番」「3番」のように指定するために使う。連番とメール（`id`/`uri`）の対応は、その回答内で保持しておき、ユーザーが番号でメール処理を指示してきたら、対応するメールに対して操作を行う。
4. 最後に何件あったか（`totalResultCount` があればそれを使う）を一言添える。

認証エラーが出た場合は、`/mcp` を実行して「claude.ai Microsoft 365」を再認証するようユーザーに案内する。
